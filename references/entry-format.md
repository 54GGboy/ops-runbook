# 条目格式

写入、更新、替换或合并方案时使用下面的固定结构。正文以够用为准，不写长篇原理说明。

````markdown
## [系统][工具] 具体问题或目标

**问题现象：** 一句话说明问题。

- 状态：未验证
- 环境：系统、终端和关键软件
- 权限：是否需要管理员权限

### 当前案例

```bash
# 写入本次案例中实际使用的完整命令；用注释解释必要变量
```

### 通用命令模块

```bash
# 变量
# 安全检查
# 执行
# 验证
# 回滚（默认保持注释，按需启用）
```

> 一句话重要风险提示。
````

## 内容要求

- 标题格式为 `## [系统][工具] 具体问题或目标`，系统和工具标签应便于只查标题。
- 更新时允许修改标题；脚本用旧标题定位原条目，用候选条目的标题作为新标题。
- “问题现象”紧跟标题，中间最多有一个空行，并压缩为一句话。
- 状态只能按事实写“未验证”或“已验证”，默认“未验证”。
- 环境写明操作系统、终端和会影响命令的关键软件或版本。
- 权限写明普通用户、`sudo`、`root` 或管理员权限要求。
- 状态、环境和权限必须在代码块外，按上述顺序各出现一次。
- “当前案例”只放本次实际使用的命令，且只有一个带语言标识的非空代码块。
- “通用命令模块”提供可替换变量、安全检查、执行和验证，且只有一个带语言标识的非空代码块。
- 回滚命令写在通用代码块中并默认注释；无法安全回滚时直接说明。
- 最后一个非空行必须是引用块形式的一句关键风险；没有特殊风险时说明适用边界。
- 合并为一个条目时，保留仍然有效的当前案例和通用模块，不机械拼接重复命令。
- 不保存密码、Token、Cookie、API Key、私钥、连接密钥或真实认证材料；统一改为 `<占位符>` 或环境变量。
