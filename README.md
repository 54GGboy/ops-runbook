# Ops Runbook

一个用于管理个人个人运维命令解决方案库的 Codex Skill。

## 功能

- 按标题查询运维方案
- 保存已解决案例
- 更新和合并已有方案
- 写入前执行格式验证和冲突检查
- 自动备份旧版本

## 安装

在 Codex 中调用 `$skill-installer`，要求从以下仓库安装：

https://github.com/54GGboy/ops-runbook

## 使用

```text
$ops-runbook 列出所有方案
$ops-runbook 搜索 Docker
$ops-runbook 查看“完整方案标题”
$ops-runbook 保存刚才解决的问题
